3 · What round 8 found2 halves, independent, both NOT CONVERGED

Four false greens — three of them written the same day

The one that matters most

Every mutation written for fork (a) asks whether a privilege was added. The fingerprint that was deleted carried both directions — SELECT was in REL_PRIVS, so a revoke moved it. One statement revoking every session-role read in M4:

digest exit=0 · RULE 3 named 0 problems · assertions exit=0

A total read outage — no logged-in user can read a single M4 row — certified as "M4 is PRESENT as expected" by the gate that guards an irreversible cutover. Same class as the round-7 Blocking this branch itself filed, on the read side instead of the write side.

And the fix contained the next one

The first repair used … | grep -q. Under set -o pipefail, grep -q exits on match, SIGPIPEs the producer, and the pipeline returns the producer's status — so it reported MUTATION SURVIVED on precisely the runs where the problem was found. Third pipeline-status-read-as-verdict in this repo.

5 · Two things worth your attentionneither needs an answer today
Phase 6 is arguably due again

This is the fifth non-converging round on M4 v2, against a trigger of four — the trigger bought with twelve rounds of the blob-addressing spec. Phase 6 has already run twice; #2 produced fork (a). ADR-0013 wrote down its own falsifier: if the next round finds defects in the INSTRUMENT rather than the SCHEMA, go straight to 0027 with the assertions as the only guard. Round 8 found both, which does not settle it. Round 9 is the cleaner test, because round 8's findings are now closed.

The review halves must stop sharing a database

One of Codex's two Blockings was an artefact: both reviewers ran mutate-schema.py against the shared postgres simultaneously, and it reported 23/63 where an isolated run gives 63/63. The harness has no lock. This repo already has a memory for the shape — an instrument that edits shared state corrupts its peers — recorded last time as two reviewers getting 23/44 and 44/44 on one commit.
